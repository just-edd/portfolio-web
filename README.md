# 🌐 Terminal Portfolio
A personal portfolio designed as an interactive terminal.

## ✨ About
This is my personal developer portfolio, built to look and feel like a terminal.
Instead of a traditional portfolio layout, you can interact with it using commands.
For example, command `help` will show you everything you can do. But there are some secret commands that you won't see with this command.
Additional commands can be added to the `config.ts` file; simply follow the instructions provided in that file.

## ⚡ Features
- Interactive terminal interface
- Command-based navigation
- Typing animation
- Custom terminal styling
- Clickable links
- Command history
- `clear` command
- Developer-focused aesthetic
